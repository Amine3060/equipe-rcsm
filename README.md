# Vol Colibri - Jeu d'aventure textuel

Mini-projet HTML/CSS (TP Initiation Web).

Tu es Alex, pilote d'un petit avion de transport. Ta mission : livrer des médicaments au village de Valmeire, dans les montagnes. À toi de faire les bons choix !

## Comment jouer

Ouvre le fichier `index.html` dans ton navigateur, puis clique sur les boutons pour faire avancer l'histoire.

## Contenu

- 15 pages au total (1 accueil + 14 scènes)
- 7 fins différentes (3 bonnes, 3 neutres, 1 mauvaise)
- Boutons personnalisés avec icônes (Font Awesome)
- Une seule feuille de style pour tout le site
- Une petite animation CSS (avion qui flotte sur l'accueil, apparition des cartes)
